# 棋墩墩

<p align="left"><img src="public/icon-512.png" width="72" height="72" alt="棋墩墩图标：一摞四枚圆棋立在棋盘上"></p>

用中国象棋那 32 枚棋子玩的一种吃墩游戏，也叫「掀棋」「打棋摞」。不比棋艺，比的是谁把牌摞收得多。

## 棋子

32 枚、7 个职级、14 档。每级红黑各一色：兵卒 5+5，炮 / 车 / 马 / 相（黑方「象」）/ 士（红方「仕」）各 2+2，将（黑）帅（红）各 1。

大小一律**黑 < 红**，同职级红压黑：

```
卒 < 兵 < 黑炮 < 红炮 < 黑车 < 红车 < 黑马 < 红马 < 黑象 < 红相 < 黑士 < 红仕 < 黑将 < 红帅
```

红帅全场最大，压得住黑将。兵和卒算同一个职级，只是卒比兵小一档；只有将帅这一级允许红黑配成一组。

牌上还有个点数，**只用来抽签，与大小无关**：兵卒 7、炮 6、车 5、马 4、相 3、士 2、将帅 1，红黑同点。

## 一局怎么走

**摆摞**。32 枚全部随机码扣，面朝下码成 8 摞、每 4 张，不按大小排——谁都不知道哪张在哪。2 人局每人摸 16 枚，4 人局每人 8 枚（没有 3 人局）。

**抽签**，全局只抽这一次：起抽人从 8 摞里挑一摞，摊开后点哪张抽哪张。翻出来的这张当场各家都看得见点数，进手之后跟着扣。从起抽人自己开始顺时针数，数到谁，谁就是这 8 摞怎么分的**处置人**，也是第一轮的先出人。

**分牌**。处置人从三种拿法里挑一种，不能指名把哪一摞给谁：

1. **层层轮流分**——每摞从顶上那张起，从处置人自己开始顺时针一人一张、一人一层；
2. **整摞轮流拿·从左**——处置人拿最左那摞，然后顺时针一人一摞；
3. **整摞轮流拿·从右**——同上，从最右边那摞开始。

8 摞一次分完，进牌局。

**吃墩**。轮流出牌，一轮叫一墩，最大的那家把整墩收走、4 张码一摞摞好。

**结算**。必须全部打完才结算。收来的牌只数张数，零头随意摆：**比总张数，多者赢；完全相同算和局**——不重开、不加赛、不判先后。

## 两种玩法

**明棋**：出牌即亮。跟牌比场上当前最大那一家（不是只跟上家），而且**张数要对得上**——单应单、对应对、几对几，不同张数不能互压。手里有同张数且更大的**必须出**，拆对也得出；压不过就抵押。

**暗棋（扣棋）**：先出人决定这一墩出单张、对子还是几条，牌扣着出，他自己那套在桌面上也是扣着的。其余几家**同时**暗出：张数对得上就必须出，但**不要求比对方大**，可以故意出小的喂牌；凑不出相同张数才抵押。全员出完先停约两秒，再一起翻开，最大的那家收走整墩。

两种玩法只差在「亮不亮牌、依次还是同时、必不必压」，成组、张数、抵押、收牌全一样。

## 几条细则

- **成组**：同职级同色手里有几张就能一起出几张（兵卒最多 5 张）。成组不是必须的，对子想拆成单张出也行。
- **抵押**：压不过或凑不出同样张数，就弃相同张数给赢家；手里不够就有几张弃几张。弃的牌归赢家，跟赢来的牌一起摞、一起计数。
- **同档**：一样大不算和，顺时针靠前（先出）的那家赢，明暗都一样。
- **下一墩**由这一墩最大的人先出。顺时针只用来定明棋的跟牌顺序和并列判赢。
- **跨局**：下一局由上一局赢家起抽；打完并列（没人赢）签就不动，仍由上局那位起抽。

## 想上手

```bash
npm install
npm run dev      # 浏览器版，电脑和手机一套界面：http://localhost:5199 —— 这一条就把页面和那张牌桌一起端出来，同网的设备直接打开终端印出来的局域网地址就能进候场厅
```

不想开浏览器就在终端里玩：

```bash
npm run play -- --players=2 --mode=kou --level=hard       # 人机对战
npm run selfplay -- --players=4 --mode=ming --games=400   # 电脑对电脑出统计
```

`--mode=ming|kou` 选明棋暗棋，`--players=2|4` 选人数，`--level=easy|greedy|hard` 选电脑难度，`--seed=N` 复现同一副牌。

上面这些规则一条一条都写在 [`rules.json`](rules.json) 里——职级、每级几张、一摞几张、明暗两栏怎么比、并列怎么判，改它就行，不用动代码。
