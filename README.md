# 棋墩墩

<p align="left"><img src="public/icon-512.png" width="72" height="72" alt="棋墩墩图标：一摞四枚圆棋立在棋盘上"></p>

用中国象棋那 32 枚棋子玩的一种吃墩游戏，也叫「掀棋」「打棋摞」。不比棋艺，比的是谁把牌摞收得多。

## 棋子

32 枚、7 个职级、14 档。每级红黑各一色：兵卒 5+5，炮 / 车 / 马 / 相（黑方「象」）/ 士（红方「仕」）各 2+2，将（黑）帅（红）各 1。3 人局在这一套上去掉一枚黑卒、一枚红兵，只剩 30 枚。

大小一律**黑 < 红**，同职级红压黑：

```
卒 < 兵 < 黑炮 < 红炮 < 黑车 < 红车 < 黑马 < 红马 < 黑象 < 红相 < 黑士 < 红仕 < 黑将 < 红帅
```

红帅全场最大，压得住黑将。兵和卒算同一个职级，只是卒比兵小一档；只有将帅这一级允许红黑配成一组。

牌上还有个点数，**只用来抽签，与大小无关**：兵卒 7、炮 6、车 5、马 4、相 3、士 2、将帅 1，红黑同点。

## 一局怎么走

**摆摞**。整副牌随机码扣，面朝下摞成几摞、一摞几张都由 `rules.json` 定，不按大小排——谁都不知道哪张在哪。2、4 人局是 32 枚摆 8 摞 × 每摞 4 张，每人摸 16 枚／8 枚；3 人局去掉一枚黑卒、一枚红兵，30 枚摆 10 摞 × 每摞 3 张，每人 10 枚。

**抽签**，全局只抽这一次：起抽人从任一摞里挑一摞，摊开后点哪张抽哪张。翻出来的这张当场各家都看得见点数，进手之后跟着扣。从起抽人自己开始顺时针数，数到谁，谁就是这些摞怎么分的**处置人**，也是第一轮的先出人。

**分牌**。处置人从这一档留下的拿法里挑一种，不能指名把哪一摞给谁：

1. **一人一层拿牌**——从最上面那层起，整层归一家：处置人先拿第一层，然后顺时针一层一家（一层＝每一摞各取一张，横着切一刀）。层数除得尽家数就轮得完，2 人局 4 层轮两圈、一人两层；
2. **整摞轮流拿·从左**——处置人拿最左那摞，然后顺时针一人一摞；
3. **整摞轮流拿·从右**——同上，从最右边那摞开始。

3 人局只留第 1 种：10 摞 × 每摞 3 张＝3 层，正好一层一家、各家 10 枚；整摞轮流拿必然拿成 12／9／9 不等张，规则表里那一档的 `ways` 就只写了 `layered`（引擎判合法着法时也不给另外两种）。一次分完，进牌局。

**吃墩**。轮流出牌，一轮叫一墩，最大的那家把整墩收走、4 张码一摞摞好。

**结算**。必须全部打完才结算。收来的牌只数张数，零头随意摆：**比总张数，多者赢；完全相同算和局**——不重开、不加赛、不判先后。

## 两种玩法

**明棋**：出牌即亮。跟牌比场上当前最大那一家（不是只跟上家），而且**张数要对得上**——单应单、对应对、几对几，不同张数不能互压。手里有同张数且更大的**必须出**，拆对也得出；压不过就抵押——垫的牌**反扣**着，谁也不知道垫了什么，收尾也不翻，悬念留到最后一刻。

**暗棋（扣棋）**：先出人决定这一墩出单张、对子还是几条，牌扣着出，他自己那套在桌面上也是扣着的。其余几家**同时**暗出：张数对得上就必须出，但**不要求比对方大**，可以故意出小的喂牌；凑不出相同张数才抵押。全员出完先停约两秒，再一起翻开，最大的那家收走整墩。

两种玩法只差在「亮不亮牌、依次还是同时、必不必压」，成组、张数、抵押、收牌全一样。

## 几条细则

- **成组**：同职级同色手里有几张就能一起出几张（兵卒最多 5 张）。成组不是必须的，对子想拆成单张出也行。
- **抵押**：压不过或凑不出同样张数，就弃相同张数给赢家；手里不够就有几张弃几张。弃的牌归赢家，跟赢来的牌一起摞、一起计数。
- **同档**：一样大不算和，顺时针靠前（先出）的那家赢，明暗都一样。
- **下一墩**由这一墩最大的人先出。顺时针只用来定明棋的跟牌顺序和并列判赢。
- **跨局**：下一局由上一局赢家起抽；打完并列（没人赢）签就不动，仍由上局那位起抽。

## 想上手

```bash
npm install
npm run dev      # 浏览器版，电脑和手机一套界面：http://localhost:5199 —— 这一条就把页面和那张牌桌一起端出来，同网的设备直接打开终端印出来的局域网地址就能进候场厅
```

不想开浏览器就在终端里玩：

```bash
npm run play -- --players=2 --mode=kou --level=hard       # 人机对战
npm run selfplay -- --players=4 --mode=ming --games=400   # 电脑对电脑出统计
```

`--mode=ming|kou` 选明棋暗棋，`--players=2|4` 选人数，`--level=easy|greedy|hard` 选电脑难度，`--seed=N` 复现同一副牌。

上面这些规则一条一条都写在 [`rules.json`](rules.json) 里——职级、每级几张、一摞几张、明暗两栏怎么比、并列怎么判，改它就行，不用动代码。

## 几个人一起玩（联机模式）

- 首页四块入口点进去各是**一整屏**，不是盖在首页上的一张卡（没有半透黑底，也没有「点空白关掉」那回事）：四块同级同尺寸——2026-10-09「关于」「设置」从原先压在页脚的小链接升格成和玩法两块一样大的入口卡，不再放最下面。「单机模式」那张开桌卡就三排选项＋一颗主按钮「开桌」（`npm run play -- --seed=N` 那句照旧管种子复现）；上局怎么摆的存本地（`qdd.solo`，只存人数/玩法/电脑水平三格），下次进来**预填进那三排**、另用一行小字交代来源——不给「按上局配置开局」那种一键绕过这张卡的重按钮（2026-10-09 用户点名：按钮太重、别直接开局）；「联机模式」那一屏就是**同网桌列表**——一行一张桌，**整行就是热区**（行本体就是真 `<a>`，点哪儿都进桌，悬上去看得见去哪儿）：**头一排是桌名**（认桌就靠这一行——两台设备各开一张时，光有 IP:端口分不清哪张是谁的，2026-10-09 用户点名「加个名字」），第二排是状态徽章（等开局／正在打）·人数·玩法·第几局·空位（还空着的高亮、坐满了的压暗），第三排是那条地址（悬着可整条选中拷走）；坐满了的整行压暗、不装成能点。**桌名纯自动、不给人填**：谁先在房主位坐下这桌就叫谁的（`A1 的桌`），只定一次、不跟着房主位交接改——名字飘了就等于没有名字；还没人在房主位坐下过的那排念「还没定房主」（这句文案本体住在 `discover.ts` 的 `roomName`，列表行和候场厅标题同源）。这一屏一进来就摆一句「正在寻」、寻到之前一直摆着，第一轮寻呼要是赶在握手之前就挂起来、连上当场补发（2026-10-09 用户：「刚开始还以为没有，像有 bug」）；寻回来之后照旧每五秒一轮，不用挨个人按。一台都没寻到时那一格不空着——摆一块虚线空状态（「这台网上还没寻到开着的桌」＋一句下一步怎么办，那句兜底说明不再孤零零飘在页脚）。底栏两颗是「在这台机器开一桌」（主按钮，钉在这儿不跟着列表滚走）和「返回」。
- **链路是一屏一层：点入口换页面，不叠卡。** 首页 →「单机模式」→（开桌卡，一拍开局）→ 牌桌；首页 →「联机模式」→（在这台机器开一桌，或点列表里那条地址）→ 候场厅 →（开局那一刻自动）→ 牌桌。玩法链路那三处出口（开桌卡／联机模式那一屏／候场厅）念的都是同一份「返回」；「关于」「设置」那两屏的出口也念同一份。候场厅那一颗离开这桌、回到「联机模式」那一屏：椅子留给令牌，回来凭它还坐这一位；只剩自己一个活人时先问一句再散桌（口径见下）。它不再兼任「看牌桌」——那一屏整屏盖着牌桌，掀开看见的其实是首页，那颗按钮撒过谎。**牌桌右上角那颗故意不叫「返回」**：它散的是「这一局我不打了」（联机念「离桌」、单机念「换桌」），跟「换一层看」不是一件事，共用一个词人就分不清哪一颗会把这一局丢掉；而且**单机那颗落回开桌卡**（2026-10-09 D3-b：上局配置就在眼前，一拍再来一局），不落在来路那一屏；联机那颗落回候场厅——两句都是「去哪儿再开」，不是「回首页」。候场厅那一屏的「现在该干什么」念在标题正下（六种处境各一句，状态机住 `home.ts` 的 `lobbyGuide`）；开局那颗贴在配置正下，不再沉底栏；二维码收进「邀请朋友」折叠条（details，默认收起，键盘可达）。「清账重开」殿后底栏，措辞带省略号、确认弹窗照旧。
- **在这台机器开一桌**＝坐下就是房主：自动落到这桌的「家」那把房主位，改配置和按开始都在你手上。那把要是已经被别人坐过（哪怕只是掉了线）就不硬挤，界面退回手挑，摘人家椅子这种事不自动发生。
- **进门落在哪一屏看的是地址上那句意图，不是这台机器是谁**：终端横幅印的那条局域网地址、候场厅那个二维码、同网桌列表里那一条，都自带 `?join=1`，扫开／点开直接落进候场厅并落座（客户端只递一句「给我挑一把空椅」`seat:-1`，挑哪一把归桌定——两台手机扫同一个码不会各挑一把再撞一起）；把端口自己敲成一条**裸地址**（`http://192.168.1.11:5200/`）的人先落首页自己挑。房主位**空着**时，桌第一把给的就是它（`Table.freeSeat`，2026-10-10 起）：谁先进来谁当房主，和「在这台机器开一桌」落到的是同一把椅子——一张桌总得有人开局；原来一律绕开房主位，于是扫码进来的人落 P2、房主位在 P1 空着，屏幕上谁都没有「开始这一局」那颗（用户原话：「联机我一进去就是 P2，明明 P1 也是空着的」）。那把**有人拿着**（坐着，或者掉了线、凭令牌还等着回来）才绕开它和「家」那把往后挑；四把椅子都有主了才回一句「这桌没空椅子了：每把都有人拿着，掉线的椅子两分钟后才还给这桌」。**自己挑椅子的人另有一道闸**：一把**还从没人开过**的房主位（这桌的房主位一次都没坐上过真人，存档里 `opened` 还是假）不**跟着**他挪——他要是从同网列表里点进来、手上又只点了第 2 把，房主位不会挪到他屁股底下（`settleHost` 那条 `byJoin && !opened`）。2026-10-09 用户实测的「两个房主」防的就是这个：两台设备各开一张桌，人从同网列表里点错一条（列表里能点到的本来就不是自己那张，见 `listFound`），进去就坐上了另一张桌的房主位，两边屏幕上各自念「房主位 · 你在这儿」，谁也看不见谁。他自己挑了普通椅子、房主位又空着时，候场厅那句会直说「房主位 P1 还空着——点那一行的『坐下 · 当房主』」（`lobbyGuide`），点那一行就换过去了，不用先让座；而桌自己把掉线的房主位收回来再交给**已经坐在这桌的活人**（`restHost`）不受上面那道 `opened` 闸限制——那种时候这桌本来就有主，只是人走开了，不接着交给活人这桌就卡死。同理，**一把椅子都没人坐过的桌压根不列进同网列表**（`listFound` 那条 `free < players` 的过滤）：那不叫「开着的桌」，点进去只会当场被推上房主位。
- **一台机器上两张桌不许写同一份存档**：起桌前先在存档旁边占一条（`table.json.lock`，跟存档一起被 .gitignore 盖住），占不着的那张当场开不起来，念的是「这份存档被哪个端口、哪个进程占着，先关那张，要么给这张另加 `--save=` 另一份文件」。占着的进程已经没了（前人挨 SIGKILL 走的留条）不算闸，直接接管；收桌时只摘自己写的那条。条上还写着「占的是哪一份存档」的绝对路径——只认进程号不够：把项目整个拷一份再开一桌，拷走那条上写着一个还活着的进程号，可那位占的是原来那一份，跟副本无关（这一档就是 `npm run smoke` 量出来的，它每场都拿副本开桌）。**比对的是那个文件，不是那串路径**：占位条上写的路径要认到实底（软链跟 `/tmp`、`/var` 那种写法都算同一条），不然同一个存档换个写法就被看成两份，闸当场失效——2026-10-02 桌面版就是这么撞上的：Electron 交回来的 userData 是 `/private/tmp/…`，而终端上 `--save=/tmp/…` 写的还是 `/tmp/…`。这只手是 `room.ts::canonicalSave`（存档往往还没落盘，所以认的是父目录的实底再接回文件名）。闸在 `src/node/room.ts::claimSave`。
- **房主位只往「没人拿着」那把上走**：现任还连着，别人坐下就只是坐下（坐回「家」那把的那位也一样），开局那颗不会被一句确认都没有就从人家手上踢走——`homeSeat` 记的是椅子不是人，「谁曾经坐过一次 P1」不算身份。真要还回去只剩一条路：代持那位自己按「让座」，房主位当场还回「家」那把（坐在「家」那把的真房主还是让不成座，这桌得有人开局）。房主位一跳，候场厅就说一句「房主位刚交给 P1 · K7 手上，上一把在 P2 · P4 手上」，六秒自己收掉——不说就只有「房主位」那三个字在行之间跳，谁也不知道换了人。这一句只报快照里就写着的事：位落在一把「挂着令牌但人没连着」的椅子上时念成「P1 · K7 那把（那位还没连着）」，不写成「交给 K7」教人等一个不会回来的人。
- **椅子那把钥匙不跟牌局共用那条随机流**：入座发的令牌走 `node:crypto` 的 `randomBytes`，不是从 `setup.seed` 那条流上取的。为什么要分家——`seed` 随每一份快照发给全桌（状态栏、战报抬头、报错那句都念它，为的是「按种子复现这一副牌」），而 mulberry32 只有 32 位状态：照那条流往外算，桌上任何一个连得上这条端口的人把自己收到的 seed 代进去，就把每一把椅子的令牌全算出来了，那句「这把椅子坐了人」当场等于没有。**牌面要能复算，身份不能**。手是 `src/node/table.ts::join`，闸在 `net.test.ts` 那一节「椅子令牌不许是牌局那条种子的函数」，刀谱 `seat-token`。
- **联机暗棋的手牌保密建立在「同桌可信」上**（2026-10-02 架构体检把这笔账翻出来，写在这儿免得下一个人再「发现」一次）：快照里带着原始 `seed`，而 `createGame` 是 `(rules, seed, players, drawer)` 的纯函数——连得上这条端口的人拿一份快照就能本地整副重放全桌扣牌；`pieces.ts` 的 id 又按职级连续编号、职级表随快照的 rules 一起发，未开牌的 id 可逐张反推牌面。这两条**是既定取舍不是疏漏**：`seed` 随快照发为的是「按种子复现这一副牌」（上一条就靠它），而局域网朋友局的同桌本来就半可信——朋友拿调试器偷看你的牌，正确处置是这人不值得再开一桌。**升级触发**：这桌哪天要能被陌生人连上（公网对局、匹配开房），保密就得起协议级改造——只摘 seed 不够（id 那条腿独立成立），只换 id 也不够（seed 还在），要么双堵、要么走「服务端权威、客户端只收增量视图」，届时 `net.test.ts` 那条「快照带 seed／id 可推牌面」的检测断言会先红，逼着改的人读完这段再动手。`src/net/wire.ts::snapshotFor` 头上那段注释把这话也说了一遍。摸签那一张也在这条账上：触屏「点哪张抽哪张」递上来的 `pieceId`，桌只验「真在这一摞里」，验不了你为什么挑它——知道 seed 的人能把点数抽得对自己有利，先出权跟着一起挑。这是同一条取舍在摸签阶段的延伸，不是漏闸；公网化改造时跟 seed 一起收。
- 寻不到桌不等于不能玩：宿主那头加了 `--no-discover`、或者路由器开了 AP 隔离，这一页就一条也不响（那句兜底的话会写在清单底下）。照终端横幅里那条局域网地址手动敲，一样进得来。

## 装到手机上（安卓 APK）

- `npm run apk:debug` 一把出包：`vite build` → `cap sync android` → `./gradlew assembleDebug`，产物是 `android/app/build/outputs/apk/debug/app-debug.apk`，打完顺手抄一份到 `release/qdd-android-<版本>-debug.apk`；正式分发的包走 `npm run apk:release`（名字不带 debug，签名口径见 RELEASE.md），跟桌面的安装包放一起。APK 的 `versionName`／`versionCode` 从 package.json 现读（gradle 那头按 semver 摊成整数码），别在 android/ 里再养一份版本号。要 JDK 21 和 Android SDK——脚本里的 `JAVA_HOME` 是问 `/usr/libexec/java_home -v 21` 要的（不写死路径、不动你的 dotfiles），SDK 路径读 `android/local.properties`（每台机器自己生成，那条被 `android/.gitignore` 盖着）。
- APK 是**纯客户端**：那张桌是一个 Node 进程（`npm run host`），装不进包里。所以「联机模式」那一屏在 APK 里不列同网的桌，改成**手填桌地址**：桌面机器上跑 `npm run host`，把它打印的 `http://192.168.1.11:5200/` 里那段 `192.168.1.11:5200` 敲进那一格，按「连这张桌」就进候场厅。**端口必须写全**——桌的端口是 `--port` 说了算，猜错的症状是「莫名其妙连不上」，所以读不出端口那串就地拦下、不猜一个。填过一次存在本地，下次进来还用它。
- 那两处岔路是外壳逼出来的，不是随手关的：WebView 发不了 UDP 广播，寻呼那一套在 APK 里没有宿主可代跑；页面 origin 就是它自己，没有「同源的一张桌」可抄。`capacitor.config.json` 里 `server.androidScheme` 定成 `http` 是让那条连接走 `ws://`（https 页面连 `ws://` 会被当混合内容拦下），`cleartext` 开着才允许连局域网里那台机器。浏览器那一头一个字没变：还是同源、还是同网桌列表。
- 「单机模式」在 APK 里照旧能打，不联网。「关于」「设置」两块也照旧（设置里那颗声音开关在 WebView 里一样使）。装进手机、真连一张桌、码能不能扫通，这几件得在真机上验。

## 装到桌面上（macOS / Windows）

- 桌面外壳**不重写界面**：`desktop/main.ts` 把 `src/node/host.ts` 那一桌当**子进程**拉起来，窗口开 `http://127.0.0.1:端口/`——同源、同网寻呼、二维码整条路跟浏览器里一模一样，所以「手填桌地址」那一格只有 APK 需要（WebView 起不了桌）。走子进程而不是 import 进来，是为了不碰 host.ts 那句 `process.argv.slice(2)` 和它的退出码：主进程要是被那桌带着 exit，窗口就没机会说「这桌起不来」。
- 四条命令是一条链：`npm run desktop:run`（开发时开着跑）→ `npm run desktop:selftest`（起桌→拉页面→`/whoami` 认答话→收桌，只看退出码）→ `npm run desktop:mac`／`npm run desktop:win`（产物在 `release/`）。**判断全住在 `desktop/launch.ts`**（端口怎么让、给房主那串参数、窗口开哪条地址、自检算不算过），那份文件一个字不引 electron，所以进得了 Node 测试，闸是 `src/test/desktop.test.ts`（`test:desktop`）；`main.ts` 只管 Electron 那几件事：起子进程、等它开口、开窗口、收尾。
- 端口从 5200 往后让——`npm run host` 那一条正坐着人的时候让开，不该反过来把它挤掉；让满 20 个才报一句人话，别一路找到 65535。试端口照 `0.0.0.0` 的绑法试，因为 host.ts 绑的就是它，拿 127.0.0.1 试会看走眼。存档落在系统给这个 App 的目录（mac 是 `~/Library/Application Support/chess-dundun/table.json`），**不落在仓库根那份活存档上**：一台机器上桌面版跟 `npm run host` 各用各的账，真去抢同一份会被 `room.ts::claimSave` 当场拒掉。窗口关掉的收尾发 SIGTERM，走的是 host.ts 里那句先存档再退的 `quit()`，不硬杀。等桌开口那一段接的是子进程的 `exit`：它自己走了（占不着存档就是这一档）当场认输、立刻念「这桌起不来」，不让人对着一台没动静的机器干等满 15 秒——2026-10-02 这一句之前查出来的：那时等的是 `child.killed`，而那只有收尾 `kill()` 过之后才可能为真，等于没接。
- 外壳挨强退（Force Quit）、崩了、或者被 `kill -9`，那张桌**不许变成看不见的孤儿**：桌身上带的参数里有一条 `--watch-parent`，`room.ts::orphanWatch` 就一秒问一次「拉起我的那位还在不在」，不在就走 `quit()` 那条正路——先把这一桌存进存档、摘掉存档旁边的占位条，再退。这条只在外壳显式要的时候才装：`npm run host` 那条路的爹是终端，挂在终端里的人合上 shell 不算收桌。**2026-10-02 真复现过修之前那一版**：`kill -9` 掉外壳，macOS 把桌交回 launchd（ppid 变 1），桌照旧活着、端口和 `table.json.lock` 照旧攥着，于是再点图标永远起不来——新那张被 `claimSave` 拒，而那句理由打在终端上，从访达点开的人根本没有终端，屏幕上什么都不出现。
- 自检那条判据认的是**棋墩墩自己的答话**（`/whoami` 里 `discover.ts` 那个口令），不只认「读得出 JSON」：端口被别的进程占着时，那头也可能回一份 200 带 JSON 的东西，照单收下就是把别人的页面当自己那张桌端进窗口。这两条只证明「桌起来了、界面端出去了」——**界面在窗口里点不点得通，这一条量不到**，那一头得有人在桌面上按。
- `release/` 里只留三个正式产物：mac 的 dmg、win 的 exe、安卓的 apk——zip（mac/win）和 `.blockmap` 都是给自动更新用的，这包 `publish: null` 不会自更新，打包目标里已裁掉（`differentialPackage`／`writeUpdateInfo` 各关各的）。每次重新打包，中间产物（`*-unpacked`、`mac-arm64`）还会长回来，不用管它，想要清爽就随手删。
- mac 这包**没签名**（`identity: null`：这台机器上没有开发者证书，也不去翻钥匙串），装完第一次打开会被 Gatekeeper 拦，得在「系统设置 → 隐私与安全性」里点「仍要打开」。win 那包是从这台 mac **交叉打**的：electron-builder 退出 0、产物躺在 `release/`，仅此而已——**装得上装不上、点得通点不通，都没在 Windows 上验过**。
- 这两条在这台机器上都得吃**本地的 Electron dist**：本地那条 GitHub 加速器做了 TLS 中间人（`CN=github.com` 那张叶子证书是 `SteamTools Certificate` 签的），curl 认，Node 一律 `unable to verify the first certificate`，而 electron-builder 抓 Electron 走的是 Node。mac 那条把 `--config.electronDist=node_modules/electron/dist` 烤进了脚本（任何一台 mac 上 `npm i` 之后都有这一份，不算这台机器专属）；win 那份 `electron-v44.5.1-win32-x64.zip` 存在 `vendor/electron-dist/`（被 `.gitignore` 盖着；取的时候 sha256 要跟官方 `SHASUMS256.txt` 那一行对上），`npm run desktop:win` 默认指它。**zip 文件名里那个版本号必须跟 `package.json` 里 pin 的 Electron 一致**——对不上就当场报错退出（实测退出码 1），不会悄悄拿旧版本铺包。网络干净的那台机器、或者真在 Windows 上打，走 `npm run desktop:win:net`：那条不带 `electronDist`，让 electron-builder 自己下。
- 包里怎么摆的：`files` 只收外壳（`desktop/**/*` 加 `package.json`），`src/`、`dist/`、`rules.json` 走 `extraResources` 进 `<resources>/app` 底下，摆成 `main.ts` 里 `ROOT` 认的那个形状，而 host.ts 自己按 `../..` 回看 `dist/` 和 `rules.json`——那三样的相对关系跟仓库里一致，所以**打包没改 host.ts 一个字**。runtime 依赖是零，于是 `npmRebuild: false`、`node_modules` 一个字节不进包；`asar: false` 是因为主进程入口是 `.ts`，「asar 里跑 ESM＋类型剥离」这条路这台机器还没走过。`publish: null` 是不让包里留一份指向不存在的花名册的更新元数据（这包不会自己更新）。

## 改动怎么验

```bash
npm run verify        # 类型检查 + 规则自检 + 十套测试，一条命令
npm run smoke         # 端到端冒烟：host 和 dev 各起一桌，两条 WebSocket 当两台设备走完一整局
npm run knives        # 负向验证：一处一处把闸拆掉，看那套测试红不红、红的是不是它该红的那句
```

后两条都只在系统临时目录里抄一份仓库再跑，绝不往仓库根的 `table.json` 上落一笔（连旁边那颗 `table.json.lock` 也落在副本里）——那张桌一开桌就会写存档（`src/node/room.ts` 的 `openRoom`），拿仓库本体量等于拿你正在打的那一桌当试验品。

verify 全绿这条挂了自动挡：push / PR 会跑 `.github/workflows/ci.yml`（verify + build + smoke，electron 二进制跳过下载）；刀架（298 把）太重不上 CI，留在本机按批跑。发布走 `npm run release`（改版本号 → verify → 三端出包 → 提交打 tag），口径见 [RELEASE.md](RELEASE.md)。

副本抄什么、回档什么都写在 `tools/lib.mjs` 两处，**加新源码目录时两处都要看一眼**：`NOT_COPIED` 那份名单把 `release/`（一份 dmg 就 123 MB）和 `android/` 的 gradle 产物挡在副本外面，`syncSrc` 每把刀开拆前把 `src/` 和 `desktop/` 各自 rsync 回副本一次——只回 `src/` 的话，同一张谱子里下一把刀就砍在上一把的伤口上，红字对不上那句 `expect`，看起来像「刀钝了」，其实是上一把没还回去。

- `npm run smoke:host -- --port=5345 --no-discover`：只量房主那条跑法（端的是 `dist/`，改过界面要先 `npm run build`）；`smoke:dev` 量挂在 Vite 上的那张桌。端口有人坐着、或者寻呼那个 UDP 槽被占着，工具会拒绝开量——那样的绿没意义。
- `npm run knives -- spread --only=3`：只跑那把刀。刀谱在 `tools/knives/*.mjs`，每张谱子写清它跑哪套闸（`suite`），每一把刀只拆一处、钉着一句专属断言文案（`expect`）；一张谱子里也可以某把刀单独跑另一套闸（那把刀自己写 `suite` 盖掉）。改完源码补测试时，顺手在那儿加一条。
- `npm run knives -- wake --verbose`：把每一刀红掉的那几句全打出来——新加一把刀时先这么跑一遍，把它钉的那句 `expect` 从实际红字里抄回去，别凭记忆写。
- 有一类刀拆掉闸之后那套测试连一句 `✗` 都打不出来（当场抛）：那种在刀谱上写 `crash: true`，报告里会照实标「这把只认退出码」，别把它当成断言钉住了。**能用它的时候几乎不该用**——原来那两把（`gate` 不兜 `JSON.parse`、`fileFor` 不兜转义抛错）就是这种，改法是让测试自己接住：`src/test/net.test.ts` 里包一层 `v()`、`src/test/discover.test.ts` 里包一层 `nullFor()`，闸一抛就当场记一条 `✗`，那两把才有专属红字可钉。2026-09-29 最后一把（`no-seat-act`，拆 `src/node/room.ts` 里「没坐下就递动作」那道闸，只有冒烟走得到）也照这个思路接住了：`tools/online-smoke.mjs` 多一个 `tryUntil`（等不到回 `null`），那四处「桌得回一句」改走它，闸一拆就记一条专属 ✗ 而不再抛 ⇒ **现在全架一把 `crash` 都没有**，再撞见这种先想「让测试自己接住」，别急着记 `crash`。
- 反过来还有一类刀拆的是**冗余保险**（旁边还有别的闸挡着），单拆一道谁也看不见：那种写 `belt: true`，**绿才算合格**，报告里单列成 `belt 绿 ✓`，不混进「几把刀全红」那句成绩里；它哪天真红了，说明那层冗余其实正在挡事，那就搬回普通刀补 `expect`。这类一共九把（2026-10-01 整架跑出来报告里就是 `belt 绿 ✓` 九条）：`tools/knives/redundant-belts.mjs` 四把，`cli-index.mjs` 两把（「低界 0 号」和「重号」各单摘一遍——后面那道回查合法表还挡着），`idle-seat-expiry.mjs` 第 2 把（拆 `sweepIdle` 里 `slot.online` 那道 guard——`join` 把 `online = true` 和 `gone = 0` 一起写，在线的那位永远走不到这一行），`auto-sit.mjs` 第 7 把（代持那把不单独绕开，家那把和「没人坐过」两道还挡着），加上 `apk-addr.mjs` 第 7 把（`:5200` 那种只有端口、没有主机的写法：`normAddr` 里那条 `at <= 0` 和它上面那条主机形状检查挡的是同一件事）。**红了不只打一行**：2026-09-29 在临时副本里把一把 belt 的刀口改成有真后果，实测报告照打「belt 红了 ✗」、末尾另点一行、整架**退出码 1**——它不混进「几把刀全红」那句成绩，但也不许悄悄算过。
- `expect` 要从 `--verbose` 的实际红字里抄**够长的一段**：抄短了会蒙到别人的红（「压摞」在 `layout` 那套里三处文案都有，改成整条标题才算钉住）。有几把刀确实只能共用同一句（同一道闸拆两半），那种在 `note` 里写明白「和第 N 把共用那句」，别让它冒充专属断言。
- 搬旧批次刀口时还会撞上第三类：刀口对得上现源码、拆了却**一句都不红**。那种既不是 `belt`（旁边得有别的闸挡着才算冗余），更不能编句 `expect` 蒙成红——它说明改版之后这一处已不自带可测后果，**搬不进来**。例：#48「宽度优先」之后，摊开地盘那两处（`top`、间距里的 `bandH / rows`）挪动都不改变落点，而 `layout.test.ts` 算带子读的是被测代码同一个 `handBand()`，自洽，量不出差别（`tools/knives/band-lift.mjs` 头部把这三把的去向写明白了）。**要让它重新有闸，得先给它一条不读被测代码自己算的断言**——这条已经走通过一次：2026-09-29 给 `band.top` 加了一条「上界只让按钮条底边一条缝」（测试自己按 `ctrlLift` 算那条底边），b5 A 那把就从「搬不进来」变回钉得住的红，`test:layout` 因此多出 6 条断言（993 → 999）。同一批的 B（`Math.min(stepFull, bandH / rows)` 拆成 `stepFull`）仍旧量不到：六块桌面上 `bandH / rows < stepFull` 只在 `rows = 3` 那一档成立，而合法手牌最多 16 张、16 张在两排里就铺得下 ⇒ 那段根本走不到。这**不是 `belt`**（belt 要「旁边另有闸挡着」，走到不到的那段没有对手），只能记在第三类里。还有更干脆的一种：那个函数整个不在源码里了，连刀口都无从抄起——批3 的 F 拆的是 `resizeMatch`（换人数时伸缩老账本），#47「换人数＝换本子」之后这函数已删，那件事改由 `resize-book.mjs` 那几把守着，所以它不搬。
- **改了源码记得回刀谱看一眼那把刀还利不利**：刀口（`from`）抄的是源码里的字面量，源码一改它就跟着动。2026-10-02 给占位条加「认软链」那一档时，`save-lock` 的 D 把当场**变绿**——它的 `to` 里写的是 `resolve(save)`，而 `claimSave` 那格改成了 `canonicalSave(save)`，两条串不再相等，刀拆的闸被自己的比对绕过去了。这不是「闸冗余」（belt 要求旁边另有闸挡着），是**刀钝了**：判据得跟着源码那一行一起改（D 的 `to` 换成 `canonicalSave(save)` 就又钉得住那句了）。所以补完闸顺手单跑一遍相关谱子（`npm run knives -- save-lock --verbose`），看红的把数跟改前对得上。
  同一天又磨绿两把，两种磨法各记一条：① **判据不许蹭随机流位**——`table-over` 的 6 号刀拆掉换牌面那趟的 `settleOver`，起抽人就退给新牌面的种子掷出来，而那条测试单看一局「赢家是不是起抽人」，撞中就是二分之一的运气；椅子令牌改走 `node:crypto` 之后桌那条流少走了两步，恰好撞中，刀当场变绿。现在钉的是连翻六局那一条（每局换 `setup.seed`，全撞中 1/64）。② **前提本身也得有断言**——`book-save` 的 7 号刀（存档不写 `rngSteps`）拆的是一串 0：那段测试只打一局就存档，而头一副牌用的就是 `setup.seed`，那条流一步没走，所以「不写流位」跟「写 0」没区别，谁都看不见。改成存前打满两局，并加一句「打到存档这一刻，那条流确实走过几步」，前提塌了会自己念出来。
- **`vite.config.ts` 也在类型检查里**（`tsconfig.json` 的 `include` 带着它）：那 56 行不是配置装饰，它 `openRoom(...)` 起了真桌、把 `/whoami` 排在 Vite 自己的中间件前面、把 `/ws` 挂在 `httpServer.on('upgrade')` 上——是全仓库唯一一块「有真行为、归构建工具管」的代码，早前两份 tsconfig 都不 include 它，`tsc` 一个字没查过它，只有 `smoke:dev` 端到端跑得到。查它零成本（0 处要改），所以钉在这儿，别再让它裸奔。
- **测试为什么有两个家**：`src/test/*.test.ts` 七套走 `tsconfig.json`（`types: ["node"]`，能 `import 'node:fs'`），`src/web/net.test.ts`（`test:link`）和 `src/web/ui.test.ts`（`test:ui`）住在出货源码那一侧，是因为它们要的是 `tsconfig.web.json` 那套 DOM 类型——搬进 `src/test/` 就换了一套 `types`，`HTMLElement` 当场编不过。它们也不进 bundle：`vite build` 只收 `src/web/main.ts` 引得到的那一块。跑起来还是同一套 `node --experimental-strip-types`，浏览器那两头是自己搭了个假 `document`。
- `src/test/desktop.test.ts`（`test:desktop`）测的东西在 `src/` 外面——它引的是 `desktop/launch.ts`，所以 `tsconfig.json` 的 `include` 现在带着 `desktop`（那里面 `main.ts` 也一起被类型检查，它引 electron）。**这条链的口径是「判断住进 launch.ts、`main.ts` 只剩 Electron 的活」**：一旦哪句判断被搬回 `main.ts`，它就同时离开类型检查和测试（`main.ts` 引 electron，进不了 node 测试），所以那套测试里专门钉了一条「判断确实住在 launch.ts」——刀谱 `tools/knives/desktop-launch.mjs` 的 L、M 两把拆的就是「引回 electron」和「在 `main.ts` 里再拼一条地址」。
- 画面到底长什么样（手机竖屏摊开、二维码扫开、真机上寻不寻得到别的桌）这里量不到，只有浏览器自动化那条路是拦着的——得你自己开 `npm run dev` 拿设备看。
