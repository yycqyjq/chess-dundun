# 棋墩墩

<p align="left"><img src="public/icon-512.png" width="72" height="72" alt="棋墩墩图标：一摞四枚圆棋立在棋盘上"></p>

用中国象棋那 32 枚棋子玩的一种吃墩游戏，也叫「掀棋」「打棋摞」。不比棋艺，比的是谁把牌摞收得多。

## 棋子

32 枚、7 个职级、14 档。每级红黑各一色：兵卒 5+5，炮 / 车 / 马 / 相（黑方「象」）/ 士（红方「仕」）各 2+2，将（黑）帅（红）各 1。

大小一律**黑 < 红**，同职级红压黑：

```
卒 < 兵 < 黑炮 < 红炮 < 黑车 < 红车 < 黑马 < 红马 < 黑象 < 红相 < 黑士 < 红仕 < 黑将 < 红帅
```

红帅全场最大，压得住黑将。兵和卒算同一个职级，只是卒比兵小一档；只有将帅这一级允许红黑配成一组。

牌上还有个点数，**只用来抽签，与大小无关**：兵卒 7、炮 6、车 5、马 4、相 3、士 2、将帅 1，红黑同点。

## 一局怎么走

**摆摞**。32 枚全部随机码扣，面朝下码成 8 摞、每 4 张，不按大小排——谁都不知道哪张在哪。2 人局每人摸 16 枚，4 人局每人 8 枚（没有 3 人局）。

**抽签**，全局只抽这一次：起抽人从 8 摞里挑一摞，摊开后点哪张抽哪张。翻出来的这张当场各家都看得见点数，进手之后跟着扣。从起抽人自己开始顺时针数，数到谁，谁就是这 8 摞怎么分的**处置人**，也是第一轮的先出人。

**分牌**。处置人从三种拿法里挑一种，不能指名把哪一摞给谁：

1. **层层轮流分**——每摞从顶上那张起，从处置人自己开始顺时针一人一张、一人一层；
2. **整摞轮流拿·从左**——处置人拿最左那摞，然后顺时针一人一摞；
3. **整摞轮流拿·从右**——同上，从最右边那摞开始。

8 摞一次分完，进牌局。

**吃墩**。轮流出牌，一轮叫一墩，最大的那家把整墩收走、4 张码一摞摞好。

**结算**。必须全部打完才结算。收来的牌只数张数，零头随意摆：**比总张数，多者赢；完全相同算和局**——不重开、不加赛、不判先后。

## 两种玩法

**明棋**：出牌即亮。跟牌比场上当前最大那一家（不是只跟上家），而且**张数要对得上**——单应单、对应对、几对几，不同张数不能互压。手里有同张数且更大的**必须出**，拆对也得出；压不过就抵押。

**暗棋（扣棋）**：先出人决定这一墩出单张、对子还是几条，牌扣着出，他自己那套在桌面上也是扣着的。其余几家**同时**暗出：张数对得上就必须出，但**不要求比对方大**，可以故意出小的喂牌；凑不出相同张数才抵押。全员出完先停约两秒，再一起翻开，最大的那家收走整墩。

两种玩法只差在「亮不亮牌、依次还是同时、必不必压」，成组、张数、抵押、收牌全一样。

## 几条细则

- **成组**：同职级同色手里有几张就能一起出几张（兵卒最多 5 张）。成组不是必须的，对子想拆成单张出也行。
- **抵押**：压不过或凑不出同样张数，就弃相同张数给赢家；手里不够就有几张弃几张。弃的牌归赢家，跟赢来的牌一起摞、一起计数。
- **同档**：一样大不算和，顺时针靠前（先出）的那家赢，明暗都一样。
- **下一墩**由这一墩最大的人先出。顺时针只用来定明棋的跟牌顺序和并列判赢。
- **跨局**：下一局由上一局赢家起抽；打完并列（没人赢）签就不动，仍由上局那位起抽。

## 想上手

```bash
npm install
npm run dev      # 浏览器版，电脑和手机一套界面：http://localhost:5199 —— 这一条就把页面和那张牌桌一起端出来，同网的设备直接打开终端印出来的局域网地址就能进候场厅
```

不想开浏览器就在终端里玩：

```bash
npm run play -- --players=2 --mode=kou --level=hard       # 人机对战
npm run selfplay -- --players=4 --mode=ming --games=400   # 电脑对电脑出统计
```

`--mode=ming|kou` 选明棋暗棋，`--players=2|4` 选人数，`--level=easy|greedy|hard` 选电脑难度，`--seed=N` 复现同一副牌。

上面这些规则一条一条都写在 [`rules.json`](rules.json) 里——职级、每级几张、一摞几张、明暗两栏怎么比、并列怎么判，改它就行，不用动代码。

## 几个人一起玩（同一张网）

- 首页点「同一张网」先落在**同网桌列表**：一行一张桌（人数·玩法·第几局·还空几把），后面跟着那条地址，点它就把浏览器递过去——点之前看得见去哪儿。这一页每五秒自己寻一圈，不用挨个人按；底栏两颗是「在这台机器开一桌」（主按钮，钉在这儿不跟着列表滚走）和「回首页」。
- **在这台机器开一桌**＝坐下就是房主：自动落到这桌的「家」那把房主位，改配置和按开始都在你手上。那把要是已经被别人坐过（哪怕只是掉了线）就不硬挤，界面退回手挑，摘人家椅子这种事不自动发生。
- **别人扫候场厅里那个码**（或者敲你那条局域网地址）进来就落座：客户端只递一句「给我挑一把空椅」（`seat:-1`），挑哪一把归桌定——两台手机扫同一个码不会各挑一把再撞一起。房主位（家那把和代持的那把）桌上一律不自动给，只剩房主位空着时回一句「这桌没空椅子了」，让人自己按「坐下 · 当房主」。
- 寻不到桌不等于不能玩：宿主那头加了 `--no-discover`、或者路由器开了 AP 隔离，这一页就一条也不响（那句兜底的话会写在清单底下）。照终端横幅里那条局域网地址手动敲，一样进得来。

## 改动怎么验

```bash
npm run verify        # 类型检查 + 规则自检 + 八套测试，一条命令
npm run smoke         # 端到端冒烟：host 和 dev 各起一桌，两条 WebSocket 当两台设备走完一整局
npm run knives        # 负向验证：一处一处把闸拆掉，看那套测试红不红、红的是不是它该红的那句
```

后两条都只在系统临时目录里抄一份仓库再跑，绝不往仓库根的 `table.json` 上落一笔——那张桌一开桌就会写存档（`src/node/room.ts` 的 `openRoom`），拿仓库本体量等于拿你正在打的那一桌当试验品。

- `npm run smoke:host -- --port=5345 --no-discover`：只量房主那条跑法（端的是 `dist/`，改过界面要先 `npm run build`）；`smoke:dev` 量挂在 Vite 上的那张桌。端口有人坐着、或者寻呼那个 UDP 槽被占着，工具会拒绝开量——那样的绿没意义。
- `npm run knives -- spread --only=3`：只跑那把刀。刀谱在 `tools/knives/*.mjs`，每张谱子写清它跑哪套闸（`suite`），每一把刀只拆一处、钉着一句专属断言文案（`expect`）；一张谱子里也可以某把刀单独跑另一套闸（那把刀自己写 `suite` 盖掉）。改完源码补测试时，顺手在那儿加一条。
- `npm run knives -- wake --verbose`：把每一刀红掉的那几句全打出来——新加一把刀时先这么跑一遍，把它钉的那句 `expect` 从实际红字里抄回去，别凭记忆写。
- 有一类刀拆掉闸之后那套测试连一句 `✗` 都打不出来（当场抛）：那种在刀谱上写 `crash: true`，报告里会照实标「这把只认退出码」，别把它当成断言钉住了。**能用它的时候几乎不该用**——原来那两把（`gate` 不兜 `JSON.parse`、`fileFor` 不兜转义抛错）就是这种，改法是让测试自己接住：`src/test/net.test.ts` 里包一层 `v()`、`src/test/discover.test.ts` 里包一层 `nullFor()`，闸一抛就当场记一条 `✗`，那两把才有专属红字可钉。2026-09-29 最后一把（`no-seat-act`，拆 `src/node/room.ts` 里「没坐下就递动作」那道闸，只有冒烟走得到）也照这个思路接住了：`tools/online-smoke.mjs` 多一个 `tryUntil`（等不到回 `null`），那四处「桌得回一句」改走它，闸一拆就记一条专属 ✗ 而不再抛 ⇒ **现在全架一把 `crash` 都没有**，再撞见这种先想「让测试自己接住」，别急着记 `crash`。
- 反过来还有一类刀拆的是**冗余保险**（旁边还有别的闸挡着），单拆一道谁也看不见：那种写 `belt: true`，**绿才算合格**，报告里单列成 `belt 绿 ✓`，不混进「几把刀全红」那句成绩里；它哪天真红了，说明那层冗余其实正在挡事，那就搬回普通刀补 `expect`。这类一共六把（2026-09-29 整架跑出来报告里就是 `belt 绿 ✓` 六条）：`tools/knives/redundant-belts.mjs` 四把，`idle-seat-expiry.mjs` 第 2 把（拆 `sweepIdle` 里 `slot.online` 那道 guard——`join` 把 `online = true` 和 `gone = 0` 一起写，在线的那位永远走不到这一行），加上 `auto-sit.mjs` 第 7 把（代持那把不单独绕开，家那把和「没人坐过」两道还挡着）。**红了不只打一行**：2026-09-29 在临时副本里把一把 belt 的刀口改成有真后果，实测报告照打「belt 红了 ✗」、末尾另点一行、整架**退出码 1**——它不混进「几把刀全红」那句成绩，但也不许悄悄算过。
- `expect` 要从 `--verbose` 的实际红字里抄**够长的一段**：抄短了会蒙到别人的红（「压摞」在 `layout` 那套里三处文案都有，改成整条标题才算钉住）。有几把刀确实只能共用同一句（同一道闸拆两半），那种在 `note` 里写明白「和第 N 把共用那句」，别让它冒充专属断言。
- 搬旧批次刀口时还会撞上第三类：刀口对得上现源码、拆了却**一句都不红**。那种既不是 `belt`（旁边得有别的闸挡着才算冗余），更不能编句 `expect` 蒙成红——它说明改版之后这一处已不自带可测后果，**搬不进来**。例：#48「宽度优先」之后，摊开地盘那两处（`top`、间距里的 `bandH / rows`）挪动都不改变落点，而 `layout.test.ts` 算带子读的是被测代码同一个 `handBand()`，自洽，量不出差别（`tools/knives/band-lift.mjs` 头部把这三把的去向写明白了）。**要让它重新有闸，得先给它一条不读被测代码自己算的断言**——这条已经走通过一次：2026-09-29 给 `band.top` 加了一条「上界只让按钮条底边一条缝」（测试自己按 `ctrlLift` 算那条底边），b5 A 那把就从「搬不进来」变回钉得住的红，`test:layout` 因此多出 6 条断言（993 → 999）。同一批的 B（`Math.min(stepFull, bandH / rows)` 拆成 `stepFull`）仍旧量不到：六块桌面上 `bandH / rows < stepFull` 只在 `rows = 3` 那一档成立，而合法手牌最多 16 张、16 张在两排里就铺得下 ⇒ 那段根本走不到。这**不是 `belt`**（belt 要「旁边另有闸挡着」，走到不到的那段没有对手），只能记在第三类里。还有更干脆的一种：那个函数整个不在源码里了，连刀口都无从抄起——批3 的 F 拆的是 `resizeMatch`（换人数时伸缩老账本），#47「换人数＝换本子」之后这函数已删，那件事改由 `resize-book.mjs` 那几把守着，所以它不搬。
- 画面到底长什么样（手机竖屏摊开、二维码扫开、真机上寻不寻得到别的桌）这里量不到，只有浏览器自动化那条路是拦着的——得你自己开 `npm run dev` 拿设备看。
